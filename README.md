# 🎮 HyperCharge UnBoxed

## 📝 게임 설명
- **장르:** 슈팅 게임 (FPS / TPS)  
- **설명:**  
  1인칭 및 3인칭 시점의 슈팅 액션 피규어 게임입니다.  
  플레이어는 피규어 캐릭터가 되어 **코인을 모아 바리게이트를 건설**하고,  
  맵을 탐험하며 몰려오는 적으로부터 **BrainCore**를 방어해야 합니다.
